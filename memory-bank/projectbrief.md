# Project brief

Create an independent public status page for all Furries PH platform surfaces and capabilities. Match Partners v2's frontend stack and make the repository easy for AI and human contributors to maintain.

The product must report observed evidence honestly: genuinely unavailable evidence is Unknown, public reachability is not workflow certification, and measured history is never fabricated. Initial scope includes API, registration, dashboards, social, moderation and related platform inventory, Supabase database/auth/capacity, Cloudflare runtime/request limits and provider incidents.
